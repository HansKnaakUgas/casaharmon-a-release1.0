# Guia de contribucion

¡Gracias por interesarte en CasaHarmonia!

1. Haz fork del repositorio y trabaja en una rama descriptiva.
2. Documenta cambios de hardware en la carpeta `docs/` del modelo afectado.
3. El codigo Python debe incluir docstrings y pasar `python -m py_compile`.
4. Abre un Pull Request describiendo el cambio y su motivacion.

Licencias aplicables segun el tipo de aporte:
- Documentacion → CC BY-SA 4.0
- Hardware → CERN-OHL-S 2.0
- Software → GPL-3.0
