# Modelo 1 — Poste de Jardin / Estacion Indoor

Monitoreo pasivo de espectro electromagnetico (1 Hz – 6 GHz) con alerta
y recomendacion de mitigacion pasiva (distancia, apantallamiento,
horarios de apagado).

## Contenido

| Carpeta | Descripcion |
| :--- | :--- |
| `hardware/` | Esquematicos, PCB (KiCad) y gerbers |
| `mecanica/` | Gabinete, dimensiones, materiales |
| `firmware/` | `hub_central.py` y dependencias |
| `docs/` | Manual de usuario y notas de cumplimiento |
