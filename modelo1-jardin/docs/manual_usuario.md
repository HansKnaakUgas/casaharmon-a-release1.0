# Manual de usuario — Modelo 1

1. Ubicar la estacion a 1.5–2 m del suelo, lejos de fuentes de ruido electrico.
2. Alimentar y esperar 60 s de calentamiento.
3. Leer el indicador: 🟢 (normal) o 🔴 (sobre umbral).
4. En caso de 🔴, aplicar mitigacion pasiva sugerida en la app/pantalla.
