# Modelo 2 — Sistema Indoor (Casa 144 m2)

Red mesh de 8 nodos de sensado + hub central con cancelacion activa de
ruido audible (ANC) y modo comparacion A/B ("switch de percepcion").

## Contenido

| Carpeta | Descripcion |
| :--- | :--- |
| `hardware/` | Esquematicos, PCB (KiCad) y gerbers |
| `mecanica/` | Gabinetes de nodo y hub, soportes |
| `firmware/` | `hub_mesh.py`, `nodo_sensor.py`, dependencias |
| `docs/` | Manual de usuario y notas de cumplimiento |
